# Musiverse

Lien du projet : [https://github.com/noepeutot/Musiverse](https://github.com/noepeutot/Musiverse)

## Prérequis

- **Node.js** (version 16 ou supérieure recommandée)
- **Git**

## Installation et Lancement

La procédure est la même pour **Windows**, **macOS** et **Linux**.

### 1. Cloner le projet

Ouvrez votre terminal (PowerShell, Command Prompt, Terminal...) et exécutez :

```bash
git clone https://github.com/noepeutot/Musiverse.git
cd Musiverse
```

### 2. Installer les dépendances

```bash
npm install
```

### 3. Lancer l'application

```bash
npm run dev
```

L'application sera accessible dans votre navigateur à l'adresse : [http://localhost:3000](http://localhost:3000)
